# Week 9 — Concept fence

## Allowed

**Everything from Weeks 1–8.** Tool arguments may now be `"number"`, `"integer"` or
`"boolean"` as well as `"string"`.

## Not yet

Frameworks · multi-agent systems · vector stores, embeddings, RAG · MCP · web
browsing, shell access, email, payments · databases · deploying to a server · a web
front end

---

## Why the fence is still up in the last week

Because the point of the capstone is to show you can build an agent **out of what you
understand**. A project that adds a framework, a database and a web UI in week 9 is
three things you cannot explain wrapped around one thing you can. An interviewer will
ask about the three.

Small, finished, measured, and explained beats large every time. Everything on the
"not yet" list is a good *next* project — and `CUT_LIST.md` says in what order.
